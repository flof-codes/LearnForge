Spec

  1. The header is one line: the focus star (only when the folder has a focus), then the folder. Phone shows the last folder, desktop the full path. The Bloom badge and the card count leave the header; the progress bar stays on top, and the “…” menu shows the full path and “Card 4 · 14 left”.
  2. Select words in the question to get Define or Tutorial. After answering, options and explanation are selectable too. Before that, options stay buttons so they give nothing away.
  3. Define: the tutor writes one or two sentences using this card as context, shown inline like a stored term. Save to card stores it, and later questions underline the term. (assumed)
  4. Tutorial: a sheet with 2 to 4 short steps, each with a diagram. Where a value varies, the diagram has a slider.
  5. Explain question: one tutorial for everything the question needs. A map of the parts comes first, then one step per part. It explains the concepts and does not pick an option.
  6. Feedback (“…” menu → Feedback on question): preset labels (several allowed), optional text, scope, then Rewrite question. The new version replaces the question in place, and Undo brings back the old one.
  7. Feedback stays on the card and guides every future question written for it. (assumed)
  8. Rating: a definition caps the suggested rating at Good, as term lookups do today. A tutorial opened before answering caps it at Hard. (assumed)
  9. States: writing (skeleton), saved, tutor paused (credits or API error: the feedback is kept and the rewrite runs later), no tutor key (plain card with folder path and no help tools).
  10. Phone: bottom sheets, selection actions sit above the bottom bar. Desktop: a popover at the selection and centred dialogs.
  11. Unchanged: question forms, rating buttons, existing menu items, tapping a stored term, keyboard shortcuts, tickets across two devices.
  12. Generated definitions and tutorials are stored per card like card_questions, so opening one again is instant and costs nothing. (assumed)

Decided

  1. A tutorial opened before answering caps the suggested rating at Hard.
  2. Feedback applies to every future question on the card by default, with a toggle for this question only.
  3. Generated definitions are saved by tapping Save to card.
  4. Tutorials are stored per card and rewritten when the card changes.
  5. On iPhone our selection bar sits above the bottom bar; the system menu is suppressed only if it gets in the way.
  6. The folder name only shows the folder; tapping it does nothing for now.
